# Обработка ошибок

| Ситуация | Ожидаемое поведение |
|---|---|
| Заголовок и текст пусты | Не сохранять, показать подсказку |
| Поля содержат только пробелы | Считать пустыми после trim |
| Заметка не найдена | Показать сообщение, не завершать приложение |
| Ошибка SQLite при записи | Сообщить о невозможности сохранения |
| Ошибка чтения БД | Показать сообщение и записать техническую ошибку в Logcat |
| Поиск ничего не нашёл | Показать «Ничего не найдено» |
| Пустой запрос | Показать все заметки |
| Пользователь отменил экспорт | Вернуться на экран без создания файла |
| Не получен Uri | Сообщить об ошибке экспорта |
| Ошибка открытия Uri | Сообщить, что файл не сохранён |
| Недостаточно места | Показать ошибку; заметки в БД не менять |
| Кириллица в экспортируемом тексте | Использовать UTF-8 |
| Очень длинная заметка | Не обрезать содержимое |
| Повторное нажатие «Сохранить» | Предотвратить дублирующие запросы |
| Поворот экрана | Состояние экрана хранить во ViewModel |
| Удаление во время поиска | Обновить результаты поиска |
