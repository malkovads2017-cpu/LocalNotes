# Тест-кейсы приложения «Заметки» (день 4)

Метод: функциональное тестирование «чёрным ящиком» и граничные проверки. Поля «Факт» и «Статус» заполняются после запуска на устройстве/эмуляторе.

| ID | Требование | Шаги | Ожидаемый результат | Факт | Статус |
|---|---|---|---|---|---|
| NT-01 | M1 | Создать заметку с заголовком и текстом | Заметка сохранена и видна в списке | | |
| NT-02 | M1 | Оставить заголовок пустым, текст заполнить | Сохранение разрешено согласно правилу непустой заметки | | |
| NT-03 | M1 | Оставить оба поля пустыми | Сохранение запрещено, показана подсказка | | |
| NT-04 | M2 | Открыть список при нескольких заметках | Отображаются все записи | | |
| NT-05 | M3 | Изменить заголовок | Новое значение сохранено | | |
| NT-06 | M3 | Изменить текст | Новый текст сохранён | | |
| NT-07 | M4 | Удалить заметку | Она исчезает из списка | | |
| NT-08 | M5 | Создать заметку, перезапустить приложение | Заметка остаётся в БД | | |
| NT-09 | M5 | Включить авиарежим, открыть заметки | Локальные данные доступны | | |
| NT-10 | M6 | Искать часть заголовка | Найдены совпадения | | |
| NT-11 | M6 | Искать слово из текста | Найдены совпадения | | |
| NT-12 | M6 | Изменить регистр запроса | Результаты не меняются | | |
| NT-13 | M6 | Ввести пустой запрос | Показаны все заметки | | |
| NT-14 | M6 | Ввести отсутствующее слово | Показано пустое состояние | | |
| NT-15 | M7 | Экспортировать одну заметку в TXT | Файл содержит заголовок и текст | | |
| NT-16 | M7 | Экспортировать несколько заметок | В файле присутствуют все выбранные записи | | |
| NT-17 | M7 | Отменить диалог экспорта | Приложение продолжает работу, БД не меняется | | |
| NT-18 | M7 | Открыть TXT с кириллицей | Текст отображается корректно | | |
| NT-19 | M7 | Экспортировать текст с переносами и спецсимволами | Символы и переносы сохранены | | |
| NT-20 | Надёжность | Быстро нажать «Сохранить» несколько раз | Нет случайных дубликатов | | |
| NT-21 | Надёжность | Удалить заметку из поиска | Результаты обновились без сбоя | | |
