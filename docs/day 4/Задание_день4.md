# Практическая работа. День 4. Слой данных мобильного приложения «Заметки»

**Среда разработки:** Android Studio. **Язык:** Kotlin. **Платформа:** Android.

## Цель
Реализовать создание, просмотр, редактирование и удаление заметок, локальное хранение, поиск и экспорт в файл.

| M3 | Редактирование | Изменение заголовка и содержимого |

| M7 | Экспорт | Сохранение заметок в TXT |

## Архитектура
Для локального хранения применяется Room (SQLite). Сущность `Note` содержит ID, заголовок, текст, дату создания и дату изменения. `NoteDao` выполняет запросы к БД, `NoteRepository` предоставляет операции приложению. Экспорт выполняется через Android Storage Access Framework (`ACTION_CREATE_DOCUMENT`), пользователь выбирает расположение файла.
