# Обработка ошибок приложения «Заметки»

Язык программирования: Kotlin. Среда разработки: Android Studio.  
Слой хранения: Room (SQLite). Ошибки репозитория и базы данных обрабатываются на уровне приложения; пользователь получает понятное сообщение, технические подробности не должны выводиться на экран.

## Правила обработки ошибок

1. Проверять заголовок до отправки данных в репозиторий.
2. Операции Room выполнять не в главном потоке, используя корутины.
3. Не показывать пользователю технический stack trace.
4. Для ошибок хранения показывать понятное сообщение и предоставлять возможность повторить действие.
5. При отмене экспорта не считать действие ошибкой.
6. Не удалять и не перезаписывать исходную заметку при неудачном экспорте.

## Журналирование

Для отладки допускается использовать `Log.e()` с описанием операции и технической причиной ошибки. Не следует записывать в журнал полное содержимое заметок, если оно не требуется для диагностики.

## Что требует дополнительной проверки

Обработку отказа в доступе к URI, нехватку свободного места, отмену системного диалога экспорта и восстановление после принудительного завершения приложения необходимо проверить на эмуляторе или реальном Android-устройстве.
