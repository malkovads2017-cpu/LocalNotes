# Интеграция слоя данных приложения «Заметки»

## Архитектура

Пользовательский интерфейс обращается к `NoteRepository`. Репозиторий использует `NoteDao`, а DAO выполняет операции с локальной базой Room.

```text
Экран / ViewModel
       |
       v
NoteRepository
       |
       v
NoteDao
       |
       v
NotesDatabase (Room / SQLite)
       |
       v
Таблица notes
```

## Структура таблицы notes

| Поле | Тип Kotlin / SQLite | Назначение |
|---|---|---|
| id | Long / INTEGER | Первичный ключ, генерируется автоматически |
| title | String / TEXT | Заголовок заметки |
| content | String / TEXT | Содержимое заметки |
| createdAt | Long / INTEGER | Время создания в миллисекундах |
| updatedAt | Long / INTEGER | Время последнего изменения |

## Основные компоненты

- `Note` — сущность Room.
- `NoteDao` — запросы к таблице `notes`.
- `NotesDatabase` — конфигурация локальной базы.
- `NoteRepository` — бизнес-логика и единая точка доступа.
- `NoteValidator` — проверка введённых данных.
- `NoteSearch` — поиск по заголовку и содержимому.
- `NoteExporter` — запись выбранной заметки в файл через URI.

## Потоки данных

Создание: экран получает заголовок и текст → ViewModel вызывает Repository → DAO добавляет запись → Room обновляет наблюдаемый список.

Редактирование: Repository получает заметку по ID → формирует обновлённую запись → DAO выполняет UPDATE → список обновляется.

Удаление: пользователь подтверждает действие → Repository вызывает удаление по ID → Room обновляет список.

Поиск: строка запроса передаётся в DAO → SQL-запрос ищет совпадения в title и content → UI отображает результат.

Экспорт: пользователь выбирает заметку и место сохранения → Android возвращает URI → NoteExporter записывает заголовок и содержимое в TXT-файл.

## Требования к интеграции

- Не выполнять операции базы данных в главном потоке.
- Для асинхронных операций использовать `suspend` и корутины.
- Для обновляемого списка использовать `Flow`.
- Обрабатывать ошибки базы и файловых операций.
- Обновлять `updatedAt` при редактировании заметки.
