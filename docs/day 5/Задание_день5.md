**Проект:** мобильное приложение «Заметки»  
**Язык программирования:** Kotlin  
**Среда разработки:** Android Studio  
**Локальное хранение:** Room (SQLite)

Исполнители и роли сохраняются согласно исходному распределению: Малкова Д. С. — руководитель, аналитик, Артюхов Р. М. — разработчик, тестировщик.

## Цель работы

Реализовать слой данных мобильного приложения «Заметки», обеспечить локальное хранение записей, операции создания, чтения, редактирования и удаления, поиск по заголовку и содержимому, а также экспорт заметки в текстовый файл.

## Функциональные требования

1. **Создание заметки:** пользователь вводит заголовок и текст, затем сохраняет запись.
2. **Просмотр заметок:** приложение отображает список сохранённых заметок.
3. **Редактирование:** пользователь может изменить заголовок и содержимое существующей заметки.
4. **Удаление:** пользователь может удалить выбранную заметку; перед удалением желательно запросить подтверждение.
5. **Локальное хранение:** заметки сохраняются в Room (SQLite) и остаются доступными после перезапуска приложения.
6. **Поиск:** поиск выполняется по заголовку и содержимому заметки.
7. **Экспорт:** выбранная заметка экспортируется в текстовый файл TXT через системный выбор места сохранения Android.

## Требования к реализации

- Основной язык — Kotlin.
- Среда разработки — Android Studio.
- Для локальной базы данных использовать Room.
- Доступ к данным организовать через DAO и Repository.
- Длительные операции выполнять с помощью Kotlin Coroutines.
- Для наблюдения за изменениями списка можно использовать `Flow`.
- Для экспорта использовать Storage Access Framework (`ACTION_CREATE_DOCUMENT` или `ActivityResultContracts.CreateDocument`).
- Не запрашивать широкие разрешения на доступ ко всему хранилищу, если достаточно URI, выбранного пользователем.

## Результат дня

Должен быть реализован слой данных приложения «Заметки». Пользователь может создавать, просматривать, редактировать и удалять заметки. Данные хранятся локально в Room и доступны после перезапуска приложения. Поиск находит заметки по заголовку и содержимому. Экспорт выбранной заметки в TXT выполняется через системный диалог Android.

## Не входит в этот этап

- Синхронизация заметок с облаком.
- Регистрация пользователей и авторизация.
- Совместное редактирование заметок.
- Шифрование заметок мастер-паролем.
- Автоматическая синхронизация между устройствами.

## Порядок работы с Git

1. Рабочие ветки `day5-*` создаются от согласованной ветки разработки после слияния предыдущего этапа.
2. Каждый участник коммитит только относящиеся к его задаче файлы.
3. Pull Request участников направляются в общую ветку разработки; порядок слияния согласуется руководителем.
4. После интеграции выполняется проверка сборки и тестов.
5. Готовая версия объединяется с `main`; при необходимости создаётся тег `day5`.
6. Тестировщик запускает `./gradlew test` и `./gradlew connectedAndroidTest`, затем заполняет фактические результаты и статусы проверок.

## Критерии приёмки

- Проект синхронизируется и собирается в Android Studio.
- Созданная заметка отображается в списке.
- Изменения заметки сохраняются.
- Удалённая заметка отсутствует в списке и базе.
- Поиск работает по заголовку и тексту.
- После перезапуска приложения заметки не теряются.
- Экспорт создаёт читаемый TXT-файл.
- Основные сценарии покрыты тестами.
