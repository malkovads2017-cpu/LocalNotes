
# Баг-репорты (день 6)

**Ответственный за тестирование:** Малкова Диана Сергеевна.

| ID | Заголовок | Шаги воспроизведения | Ожидалось | Получилось | Приоритет | Статус |
|---|---|---|---|---|---|---|
| BUG-01 | Не отображается пустое состояние | Запустить приложение без заметок | Показана подсказка о создании первой заметки | Заполняется после проверки | Средний | Новый |
| BUG-02 | Не выполняется поиск по содержимому | Ввести слово из текста заметки | В списке остаются совпадения | Заполняется после проверки | Высокий | Новый |
| BUG-03 | Не сохраняется изменение заметки | Изменить текст и нажать «Сохранить» | Изменения сохраняются | Заполняется после проверки | Высокий | Новый |
| BUG-04 | Удаление без подтверждения | Нажать «Удалить» на экране просмотра | Появляется диалог подтверждения | Заполняется после проверки | Высокий | Новый |
| BUG-05 | Пустое название принимается | Оставить название пустым и сохранить | Появляется сообщение валидации | Заполняется после проверки | Средний | Новый |

Примечание: баг-репорты являются шаблонами для фиксации результатов проверки.
Статус и фактический результат необходимо заполнить после запуска прототипа.
