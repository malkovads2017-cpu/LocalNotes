# Баг-репорты (день 3)

Каждый обнаруженный дефект регистрируется отдельной задачей (Issue). В коммите исправления указывается номер задачи, например: `fix(notes): исправлена фильтрация заметок (#N)`.

## Приоритеты

- Критичный — потеря заметок, повреждение локального хранилища или невозможность запустить приложение.
- Высокий — не работает одна из основных функций: создание, редактирование, удаление, поиск или экспорт.
- Средний — функция работает неправильно в отдельных сценариях, есть обходной путь.
- Низкий — косметический дефект интерфейса или незначительное неудобство.

## Статусы

Новый, исправлен, проверен, закрыт.
