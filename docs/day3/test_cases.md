# Тест-кейсы ядра приложения «Заметки» (день 3)

Метод: функциональное тестирование методом чёрного ящика, проверка граничных значений и ошибок. Колонки «Факт» и «Статус» заполняются после выполнения проверок.

| ID | Требование | Предусловие | Шаги | Ожидаемый результат | Факт | Статус |
|---|---|---|---|---|---|---|
| TC-01 | Создание | Хранилище доступно | Создать заметку с заголовком и текстом | Заметка создана, ей присвоен ID | | |
| TC-02 | Создание | — | Создать заметку без заголовка, но с текстом | Заметка сохраняется, отображается «Без названия» | | |
| TC-03 | Создание | — | Сохранить заметку с пустыми заголовком и текстом | Появляется сообщение о необходимости заполнить заметку | | |
| TC-04 | Просмотр | Есть сохранённая заметка | Открыть заметку из списка | Отображаются правильные заголовок и содержимое | | |
| TC-05 | Редактирование | Есть сохранённая заметка | Изменить заголовок, сохранить | Новый заголовок отображается после повторного открытия | | |
| TC-06 | Редактирование | Есть сохранённая заметка | Изменить содержимое, сохранить | Новый текст сохранён; `updated_at` обновлён | | |
| TC-07 | Удаление | Есть сохранённая заметка | Удалить и подтвердить действие | Заметка отсутствует в списке и хранилище | | |
| TC-08 | Удаление | Есть сохранённая заметка | Начать удаление и отменить подтверждение | Заметка остаётся без изменений | | |
| TC-09 | Локальное хранение | Есть сохранённые заметки | Закрыть и повторно открыть приложение | Все заметки доступны после запуска | | |
| TC-10 | Поиск | Есть заметки «Покупки» и «Учёба» | Ввести `покуп` | Найдена заметка «Покупки» | | |
| TC-11 | Поиск | Есть заметка с текстом «Позвонить врачу» | Искать `ВРАЧУ` | Найдена заметка без учёта регистра | | |
| TC-12 | Поиск | Есть несколько заметок | Ввести пустой запрос | Отображается полный список | | |
| TC-13 | Поиск | Есть несколько заметок | Ввести строку, которой нет в данных | Отображается пустой результат | | |
| TC-14 | Поиск | Есть совпадения в заголовке и тексте | Искать слово из содержимого | Заметка найдена по содержимому | | |
| TC-15 | Экспорт | Есть заметка с русским текстом | Экспортировать в `.txt`, открыть файл | Файл создан, кириллица отображается корректно | | |
| TC-16 | Экспорт | Есть заметка | Указать недоступный путь или отменить выбор | Приложение сообщает об ошибке/отмене, заметка не теряется | | |
| TC-17 | Экспорт | Есть заметка с переносами строк | Экспортировать и проверить файл | Содержимое и переносы строк сохранены | | |
| TC-18 | Ошибки | Указан несуществующий ID | Открыть, изменить или удалить заметку | Возвращается понятный результат «не найдено», приложение не аварийно завершается | | |
| TC-19 | Целостность | Есть сохранённая заметка | Отредактировать и перезапустить приложение | Сохранилась последняя версия, дубликат не создан | | |
| TC-20 | NFR | Приложение работает офлайн | Отключить сеть и выполнить CRUD, поиск и экспорт | Основные функции продолжают работать | | |
