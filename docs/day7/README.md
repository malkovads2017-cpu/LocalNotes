# День 7. Тестирование и отладка

Проект: **Мобильное приложение «Заметки»** (Kotlin, Android Studio).  
Команда: **Артюхов Ростислав Максимович** (разработчик), **Малкова Диана Сергеевна** (тестировщик).

## Состав артефактов
- `day7/test_plan.md` — тест-план (объект, окружение, виды тестирования, критерии приёмки).
- `tests/test_cases.md` — 10 тест-кейсов по методу «чёрного ящика».
- `day7/bug_reports.md` — журнал дефектов (Blocker/Critical/Major/Minor) и статус исправлений.
- `day7/requirements_coverage.md` — матрица покрытия требований ТЗ тестами.
- `tests/NoteUnitTest.kt` — модульные тесты (JUnit 4) для ключевых функций ядра.
- `tests/test_run_report.md` — итоговый отчёт о прогоне тестов до и после исправлений.
