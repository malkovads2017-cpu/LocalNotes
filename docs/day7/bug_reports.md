### BUG-01: Сохранение пустой заметки создаёт пустую карточку в списке
- **Серьёзность:** Critical
- **Приоритет:** High
- **Окружение:** Android Emulator Pixel 6 (Android 14, API 34), сборка `debug-0.9`.
- **Шаги воспроизведения:**
  1. Открыть приложение «Заметки».
  2. Нажать кнопку «+» (Создать заметку).
  3. Оставить поля «Заголовок» и «Текст» пустыми (или ввести пробелы).
  4. Нажать кнопку «Сохранить».
- **Ожидаемый результат:** Появляется предупреждение «Заметка не может быть полностью пустой», запись не добавляется в БД.
- **Фактический результат:** Приложение сохраняет пустую запись, в списке отображается пустой элемент.
- **Статус:** **Исправлен (Fixed)** — добавлена проверка через `NoteValidator.validate()` перед записью в Room.

### BUG-02: Падение приложения (Crash) при экспорте заметки со спецсимволами в заголовке
- **Серьёзность:** Blocker
- **Приоритет:** High
- **Окружение:** Android Emulator Pixel 6 (Android 14, API 34), сборка `debug-0.9`.
- **Шаги воспроизведения:**
  1. Создать заметку с заголовком `План: 2026/11*`.
  2. Открыть меню заметки и выбрать «Экспорт в файл (.txt)».
- **Ожидаемый результат:** Недопустимые символы в имени файла заменяются на `_`, файл успешно сохраняется.
- **Фактический результат:** Выбрасывается `IOException` из-за символа `/` в имени файла, приложение аварийно завершается.
- **Статус:** **Исправлен (Fixed)** — внедрена функция `NoteExporter.sanitizeFileName()`.

### BUG-03: Двойное нажатие на кнопку «Сохранить» создаёт дубликат заметки
- **Серьёзность:** Major
- **Приоритет:** Medium
- **Окружение:** Android Emulator Pixel 4 (Android 10, API 29).
- **Шаги воспроизведения:**
  1. Открыть форму создания новой заметки и заполнить поля.
  2. Дважды быстро нажать на кнопку «Сохранить».
- **Ожидаемый результат:** Создаётся ровно одна заметка, происходит возврат на главный экран.
- **Фактический результат:** В базе данных Room создаются две идентичные заметки.
- **Статус:** **Исправлен (Fixed)** — добавлена блокировка кнопки `btnSave.isEnabled = false` на время выполнения корутины сохранения.

### BUG-04: При повороте экрана сбрасывается текст в строке поиска
- **Серьёзность:** Minor
- **Приоритет:** Low
- **Окружение:** Android Emulator Pixel 6 (Android 14, API 34).
- **Шаги воспроизведения:**
  1. Ввести слово `Kotlin` в строку поиска на главном экране.
  2. Повернуть экран в альбомную ориентацию.
- **Ожидаемый результат:** Поисковый запрос и отфильтрованный список сохраняются.
- **Фактический результат:** Строка поиска очищается, отображается полный список заметок.
- **Статус:** **Открыт (Deferred to v1.1)** — не влияет на основной функционал, запланировано хранение запроса в `ViewModel` в следующей версии.
