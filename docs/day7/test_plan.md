## 1. Объект тестирования
Мобильное приложение «Заметки» для ОС Android, разработанное на языке **Kotlin** в среде **Android Studio**.  
Основные модули:
- Экран списка заметок (`MainActivity` / `NoteListFragment`) и строка поиска.
- Экран создания и редактирования заметки (`NoteEditorActivity`).
- Локальное хранилище на базе Room (SQLite).
- Модуль валидации (`NoteValidator`) и экспорта в файл (`NoteExporter`).

## 2. Тестовое окружение
- **Среда разработки:** Android Studio Ladybug / Koala, Gradle 8.x, Kotlin 1.9+.
- **Эмуляторы (AVD):**
  - Pixel 6 API 34 (Android 14) — основное устройство.
  - Pixel 4 API 29 (Android 10) — проверка обратной совместимости (minSdk 26).
- **Инструменты тестирования:** JUnit 4 (unit-тесты), ручное функциональное тестирование по методу «чёрного ящика».

## 3. Виды тестирования
1. **Функциональное тестирование (Black-box):** проверка всех пользовательских сценариев (создание, редактирование, удаление, поиск, сохранение после перезапуска, экспорт в `.txt`).
2. **Тестирование граничных значений:** пустой ввод, длинный заголовок (>100 символов), спецсимволы в имени файла при экспорте, быстрое повторное нажатие кнопки «Сохранить».
3. **Модульное тестирование (Unit-тесты):** проверка чистой бизнес-логики (`NoteValidator`, `NoteExporter`) с помощью JUnit 4.
4. **Регрессионное тестирование:** повторный прогон всех тест-кейсов после исправления дефектов Blocker и Critical.

## 4. Критерии входа и выхода
- **Критерии входа:** проект успешно собирается в Android Studio (`./gradlew assembleDebug`), реализованы все базовые экраны.
- **Критерии выхода:** пройдено 100% unit-тестов, исправлены все дефекты уровня Blocker и Critical, не менее 90% тест-кейсов имеют статус `Passed`.
